# 🎮 Esports Tournament Manager

A Java Swing desktop application for managing multi-stage e-sports tournaments, custom roster setups, and dynamic score tracking.

## 🌟 Key Features
- **Team & Roster Registration:** Register teams, assign custom roles (Duelist, Controller, Sentinel, IGL), and upload team logos.
- **Dynamic Bracket Generator:** Auto-generates tournament match-ups with progress tracking across stages.
- **Interactive History & Diagram:** Visually inspect tournament progression and click teams to view detailed stats.
- **MVP & Score Ranking:** Track individual player scores and automatically calculate podium rankings (1st MVP, 2nd, 3rd).

## 🛠️ Built With
- **Language:** Java SE
- **UI Framework:** Java Swing (`javax.swing`)
- **IDE:** Apache NetBeans

## 🚀 How to Run
1. Clone or download this repository.
2. Open **Apache NetBeans**.
3. Go to `File` > `Open Project...` and select the project directory.
4. Run `EsportsManager.java`.
